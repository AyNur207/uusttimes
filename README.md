# The UUST Times

Студенческое издание УУНиТ: Flask + Jinja2, SQLite и адаптивное газетное оформление.

## Запуск

Нужен Python 3.10 или новее. В PowerShell из корня проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:8080. Для локальной разработки с автоматическим перезапуском можно вместо последней команды выполнить `.\.venv\Scripts\python.exe -m flask --app app run --debug --port 8080`.

## Структура

```text
app.py                     # точка входа Flask CLI / WSGI
uusttimes/
  __init__.py              # create_app, конфигурация, дата в часовом поясе Уфы
  routes.py                # Blueprint с публичными маршрутами
  models.py                # SQLAlchemy, модель News
  forms.py                 # форма новости и серверная валидация
  uploads.py               # проверка и сохранение обложек
templates/
  base.html                # общий каркас, шапка, навигация, подвал, Jinja-блоки
  index.html               # опубликованные новости, пагинация и пустое состояние
  my_news.html             # публикации из текущего браузера
  new_news.html            # форма публикации
  news_detail.html         # полный текст одной новости
  account.html             # страницы-заготовки входа и регистрации
  support.html             # поддержка разработчиков
  partials/icons.html      # SVG-иконки
static/
  css/                     # собственные стили проекта
    university/            # исходный образец, не изменяется и не импортируется
  images/brand-mark.svg    # иконка издания и favicon
instance/                  # локальные данные, вне Git
  uusttimes.db             # SQLite, создаётся при первом запуске
  uploads/                 # обложки с автоматически сгенерированными именами
  .secret_key              # локальный ключ сессий, если SECRET_KEY не задан
```

Новые страницы наследуют `base.html`. Доступны блоки `title`, `description`, `styles`, `content`, `scripts`. Общие стили подключены в базе; стили отдельных страниц — через `styles`.

## Текущий этап

Работают лента `/`, «Мои новости» `/my-news`, форма `/news/new`, отдельная публикация `/news/<id>` и поддержка `/support`. Вход и регистрация пока показывают информационные страницы. Модерации нет: отправленная новость сразу получает `published` и становится публичной. Донаты подключаются через публичную ссылку внешнего сервиса. Демонстрационные новости в рабочую базу автоматически не добавляются.

## Отправка и хранение новостей

1. Откройте «Мои новости» → «Предложить новость» (или ту же кнопку на главной).
2. Заполните заголовок (3–160 символов) и текст (10–20 000 символов).
3. По желанию добавьте обложку JPG/PNG/WebP до 5 МБ и 20 мегапикселей, дату события, место и ссылку на регистрацию. Дата вводится по времени Уфы (UTC+5).
4. Нажмите «Опубликовать новость». Сервер проверит форму, сохранит запись и вернёт на главную, где будет видна новая публикация. В карточке есть ссылка на полный текст.

Таблица `news` в `instance/uusttimes.db` хранит заголовок, полный текст, имя обложки, сведения о событии, время создания и публикации, статус и случайную метку автора `author_token`. Временные метки хранятся в UTC, отображаются по Уфе. На странице показывается по 10 публикаций, новые — первыми. HTML из пользовательского текста экранируется, переносы строк сохраняются.

Обложка проверяется по содержимому, преобразуется в WebP и сохраняется в `instance/uploads/` под случайным именем; в БД хранится только имя файла. Исходное имя и метаданные изображения не переносятся. Существующие обложки не перезаписываются.

Без регистрации метка автора хранится в подписанной cookie-сессии браузера. «Мои новости» показывает только записи с этой меткой; после очистки cookies или в другом браузере список будет другим. **Это не аккаунт и не механизм доступа к приватным данным: сейчас все отправленные новости публичны.**

БД и обложки сохраняются после перезапуска. Для стабильной сессии задайте `SECRET_KEY` или сохраните автоматически созданный `instance/.secret_key`. Для переноса проекта с данными копируйте всю папку `instance/` приватным способом, не через Git.

Начальная схема создаётся автоматически через `db.create_all()` без удаления существующих записей. Изменения уже существующих таблиц при дальнейшем развитии нужно проводить миграциями; автоматического обновления схемы пока нет. При подключении регистрации метку браузера можно будет заменить связью с пользователем, а немедленную публикацию — отправкой в `pending`.

Проверки (используют отдельные временные базы, рабочие новости не затрагивают):

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Поддержка разработчиков

Кнопка поддержки ведёт на страницу `/support`: описание, порядок оплаты и ответы на вопросы. Для подключения реальных донатов:

1. Создайте аккаунт в подходящем сервисе, например [CloudTips](https://cloudtips.ru/donations). Условия, комиссии и доступность выплат уточняются у сервиса.
2. Привяжите карту для выплат **в личном кабинете сервиса**. Реквизиты карты не добавляйте в код, конфигурацию сайта или Git.
3. Создайте страницу поддержки The UUST Times и скопируйте её **публичную платёжную ссылку**. Адрес личного кабинета не подходит.
4. Создайте файл `.env` в корне проекта (можно скопировать `.env.example`) и добавьте ссылку:

```dotenv
DONATION_URL=https://example.com/your-support-page
```

Адрес в примере нужно заменить своей ссылкой. Приложение читает `.env` автоматически при запуске, в том числе через `python app.py`; путь к файлу определяется относительно корня проекта. Повторно задавать ссылку в PowerShell не нужно. После изменения `.env` перезапустите Flask. Если `DONATION_URL` уже задана в окружении, она имеет приоритет над файлом; удалить её в текущем PowerShell можно командой `Remove-Item Env:DONATION_URL -ErrorAction SilentlyContinue`.

Без ссылки или при некорректном адресе страница показывает состояние «Готовим приём донатов». Принимаются HTTPS-ссылки без встроенного логина/пароля и нестандартных портов. Проверка формата не подтверждает принадлежность или надёжность сервиса — используйте адрес, полученный в его личном кабинете.

Сумма и способ оплаты выбираются на стороне сервиса. После перехода он обрабатывает платёж и выплаты; сайт не получает реквизиты карт. Подтверждение платежа и история переводов доступны у сервиса. Нажатие кнопки или возврат на сайт не считаются успешным донатом; локальный учёт платежей, вебхуки и счётчик собранной суммы не подключены.

`.env` исключён из Git: на другом компьютере создайте его из `.env.example` и заполните настройки. В нём также можно задать необязательный `SECRET_KEY`; для переменных окружения сохраняется приоритет над файлом.

Цвета взяты из предоставленного образца `university`; это не заявление о соответствии официальному брендбуку. Внешние шрифты и библиотеки не загружаются.
