# The UUST Times

Студенческое издание УУНиТ. Начальный каркас Flask + Jinja2 с адаптивным газетным оформлением.

## Запуск

Нужен Python 3.10 или новее. В PowerShell из корня проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app run --debug
```

Откройте http://127.0.0.1:5000. Режим `--debug` предназначен для локальной разработки.

## Структура

```text
app.py                     # точка входа Flask CLI / WSGI
uusttimes/
  __init__.py              # create_app, конфигурация, дата в часовом поясе Уфы
  routes.py                # Blueprint с публичными маршрутами
templates/
  base.html                # общий каркас, шапка, навигация, подвал, Jinja-блоки
  index.html               # главная с пустым состоянием новостной ленты
  account.html             # страницы-заготовки входа и регистрации
  support.html             # поддержка разработчиков
  partials/icons.html      # SVG-иконки
static/
  css/                     # собственные стили проекта
    university/            # исходный образец, не изменяется и не импортируется
  images/brand-mark.svg    # иконка издания и favicon
instance/                  # локальные данные будущего приложения, вне Git
```

Новые страницы наследуют `base.html`. Доступны блоки `title`, `description`, `styles`, `content`, `scripts`. Общие стили подключены в базе; стили отдельных страниц — через `styles`.

## Текущий этап

Работают `/`, `/login`, `/register`, `/support` и раздача статических файлов. Вход и регистрация пока показывают информационные страницы: формы, пользователи, БД, модерация и приём платежей ещё не реализованы. Демонстрационные новости не добавлены.

Кнопка поддержки ведёт на страницу `/support`. Чтобы показать на ней переход к платёжному сервису, задайте публичный HTTPS-адрес **перед запуском**:

```powershell
$env:DONATION_URL = 'https://example.com/your-support-page'
```

Без адреса страница сообщает, что поддержка скоро появится. Платёжные реквизиты не выдумываются. `SECRET_KEY` также задаётся переменной окружения; он понадобится при подключении сессий и авторизации. `.env.example` служит справкой, автоматическая загрузка `.env` не настроена.

Цвета взяты из предоставленного образца `university`; это не заявление о соответствии официальному брендбуку. Внешние шрифты и библиотеки не загружаются.
